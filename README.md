# 🤖 Sidad AI - Advanced Telegram Assistant (Gemini 2.0)

A professional-grade AI integration project featuring a Telegram Bot and a Streamlit Dashboard, powered by Google's **Gemini 2.0 Flash** model. This project demonstrates high-level Python automation, API integration, and multi-platform deployment.

## 🚀 Key Features
- **Smart Telegram Bot:** Built with `pyTelegramBotAPI`, providing real-time AI responses with support for the Kurdish (Badini) dialect.
- **Web Dashboard:** A standalone `Streamlit` application for direct AI interaction and testing.
- **Enterprise Structure:** Fully configured with `.devcontainer` for standardized development environments.
- **Secure Architecture:** Implements `.gitignore` and environment variable management for API security.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **AI Engine:** Google Gemini 2.0 Flash
- **Frameworks:** Telebot (pyTelegramBotAPI), Streamlit
- **DevOps:** GitHub DevContainers, MIT License

## 📂 Project Structure
- `main.py`: The core Telegram Bot engine.
- `streamlit_app.py`: Web-based interface for AI interaction.
- `requirements.txt`: Managed dependencies for one-click installation.
- `.devcontainer/`: Standardized environment for VS Code users.
